# Excel Data Analysis – Sample Superstore

## Project Overview

This project was completed as part of the Veda Technology Data Analysis Internship. The main objective was to analyze the Sample Superstore dataset using Microsoft Excel and identify important sales and business insights.

## Tools Used

- Microsoft Excel
- PivotTables
- Excel Formulas
- Charts
- GitHub

## Dataset

The Sample Superstore dataset contains information about orders, customers, products, sales, profit, quantity, regions, segments, shipping modes, and dates.

## Work Done

The following analysis was performed:

1. Cleaned and organized the dataset.
2. Kept the original data separately in the `Raw_Data` sheet.
3. Created a `Working` sheet for formula-based analysis.
4. Created a `Summary` dashboard with key performance metrics.
5. Created PivotTables for:
   - Sales by Category
   - Sales by Region
   - Sales by Segment
   - Sales by Ship Mode
   - Sales by State
   - Sales by Order Date
6. Created charts to visualize the important sales information.
7. Added key findings based on the analysis.
8. Froze the header row in the raw data sheet for easier navigation.

## Key Performance Metrics

- Total Sales: 2,297,201
- Total Profit: 286,397
- Total Orders: 10,800
- Average Sales: 229.858
- Total Quantity: 37,873
- Average Profit: 28.6569

## Key Findings

1. Technology generated the highest sales among the categories at 836,154.033.
2. West recorded the highest sales among the regions at 725,457.8245.
3. Consumer was the largest customer segment with sales of 1,161,401.345.
4. Standard Class had the highest sales among shipping modes at 1,358,215.743.
5. The overall sales recorded in the dataset were approximately 2,297,200.86.

The analysis helped identify important sales patterns across categories, regions, customer segments, shipping modes, and states. Excel formulas, PivotTables, and charts were used to organize and present the results clearly.
